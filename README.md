# Website Belajar Bahasa Jepang NihongoQu
NihongoQu merupakan Website yang menggunakan bahasa pemrograman Java, PHP, HTML & CSS dan template Bootstrap. Website yang sangat simpel dengan memiliki fitur seperti flashcard dan kamus sederhana (Setara level N5), dengan sistem login oleh user.

# Syarat
Pastikan Anda sudah menginstall :
* PHP 5.6
* Java
* Browser
